| 概念                     | 本质                                            |
| ------------------------ | ----------------------------------------------- |
| Entity Reference         | 实体引用,知道关联实体是谁，但不一定加载完整数据 |
| `isInitialized()`        | 实体/集合是否已经真正加载                       |
| `populate`               | 告诉 ORM 要把哪些字段或关系加载出来             |
| `.lazy()`                | 某个字段默认不 SELECT                           |
| `Collection<T>`          | MikroORM 对 to-many 关系的管理对象              |
| `Collection.init()`      | 主动初始化集合                                  |
| `Collection.loadItems()` | 未初始化才加载                                  |
| `em.populate()`          | 给已有实体补加载关系/字段                       |
| `mappedBy`               | 当前为反向方，对方哪个字段是 owning side        |
| `inversedBy`             | owning side 对应的反向属性                      |
| Cascade                  | 对关联 Entity 传播 persist/remove               |
| orphanRemoval            | Child 脱离 Parent 后直接删除                    |
| Propagation              | 双向关系修改时同步内存中的另一侧                |
