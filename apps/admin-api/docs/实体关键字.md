| 关键词                              | 含义                                           |
| ----------------------------------- | ---------------------------------------------- |
| `manyToOne`                         | 多条当前数据可以对应一条对方数据。             |
| `oneToMany`                         | 一条当前数据可以对应多条对方数据。             |
| `oneToOne`                          | 一条当前数据只对应一条对方数据。               |
| `manyToMany`                        | 两边都可以对应多条数据，中间通过关联表连接。   |
| `mappedBy`                          | 指定拥有方的属性，写在反向方里。               |
| `inversedBy`                        | 指定反向关系的属性，写在拥有方里。             |
| `owner()`                           | 不需要参数，指定当前这一方是拥有方。           |
| `inverseJoinColumn`                 | 多对多关联表中存放对方 ID 的字段。             |
| `pivotTable`                        | 指定多对多使用哪张关联表。                     |
| `pivotEntity`                       | 指定用哪个 Entity 描述多对多关联表。           |
| `targetKey`                         | 默认用对方主键关联，也可以指定其他唯一字段。   |
| `createForeignKeyConstraint(false)` | 不创建数据库外键，但 ORM 还能查询关系。        |
| `populate`                          | 查询时把指定关系数据一起查出来。               |
| `populate: relation:ref`            | 查询时只加载关系数据的 ID，不加载完整数据。    |
| `em.populate()`                     | 查完 Entity 后，再补查指定关系。               |
| `Collection`                        | 存放多条关系数据的集合对象。                   |
| `Collection.getIdentifiers()`       | 取出集合中关系数据的 ID。                      |
| `Collection.loadItems()`            | 加载集合中的关系数据。                         |
| `Collection.loadCount()`            | 不加载关系数据，只查询数量。                   |
| `isInitialized()`                   | 判断 Entity 或 Collection 是否已经加载。       |
| `LoadStrategy.SELECT_IN`            | 先查主表，再单独查关系。                       |
| `LoadStrategy.JOINED`               | 用 JOIN 一起查主表和关系。                     |
| `LoadStrategy.BALANCED`             | ORM 自动选择 JOIN 或分开查询。                 |
| `cascade`                           | 主数据的操作自动传给关系数据。                 |
| 空 `.cascade()`                     | 不自动处理关系数据。                           |
| `orphanRemoval`                     | 从关系中移除数据时，自动删除该数据。           |
| `em.assign()`                       | 批量给 Entity 赋值，不能用嵌套对象隐式改关系。 |
| `lazy()`                            | 默认不查询这个字段。                           |
| `hidden()`                          | 序列化返回时隐藏这个字段。                     |

- `joinColumn`
    - `ManyToOne`：写在拥有方，指定当前表保存对方 ID 的字段。
    - `OneToOne`：写在拥有方，指定当前表保存对方 ID 的字段。
    - `ManyToMany`：指定关联表中当前方的字段，并配合 `inverseJoinColumn` 指定对方字段。
    - `OneToMany`：通常不写，因为它一般是反向方，使用 `mappedBy` 指向拥有方。
- `Collection.add/remove/set/removeAll`
    - `add`：增加关系。
    - `remove`：移除关系。
    - `set`：替换全部关系。
    - `removeAll`：清空关系。
    - 以上方法业务代码禁止使用。
- `primary()`
    - 一个字段：设为主键。
    - 多个字段：组成复合主键。
- `where()`
    - 查询：增加筛选条件。
    - 关系：增加默认筛选条件。
